# Localization & RTL

These rules apply to every feature, refactor, bug fix, UI change, component, Turbo Stream, and Stimulus controller — no exceptions.

**Supported locales:** `en` · `es` · `de` · `fr` · `pt` · `ar` · `fa` · `ckb` · `tr` · `ru`
**Source of truth:** `config/locales/en.yml`

## Localization Rules

- No hardcoded user-facing strings anywhere in the codebase
- All views and controllers use `t()` / `t!()` — including `placeholder`, `aria-label`, `title`, and button text
- Flash messages: `flash[:notice] = t("key")` — never a string literal
- Mailer subjects and body text use `t()`
- Stimulus controllers receive all text via data attributes from Rails views — never hardcode strings in JS
- Every new key added to `en.yml` must also exist in all other 9 locale files (use the English value as a placeholder if untranslated)
- Count-dependent strings use Rails pluralization (`one:` / `other:`) — never `"%{count} item(s)"`
- Model validation messages use `activerecord.errors` i18n keys — never inline string literals

## RTL Rules

Locales `ar`, `fa`, and `ckb` are right-to-left.

- Use logical CSS properties: `margin-inline-start/end`, `padding-inline-start/end`, `text-align: start/end`
- Never use `margin-left/right`, `padding-left/right`, or `text-align: left/right` in layout-affecting styles
- Icons adjacent to text must use `inline-flex` so they flip correctly in RTL layouts
