
Quizly UI Design System

------------------------------------
DESIGN PRINCIPLES
------------------------------------

- simplicity over decoration
- speed over animation
- clarity over aesthetics
- mobile-first design
- learning-focused interface

------------------------------------
SPACING SYSTEM

- 4px base unit
- spacing scale: 4 / 8 / 12 / 16 / 24 / 32 / 48

------------------------------------
TYPOGRAPHY

- Headings: bold, large, minimal hierarchy
- Body: highly readable, simple sans-serif
- Avoid decorative fonts

------------------------------------
COLORS

- Primary: calm blue or green tone
- Background: neutral light/dark
- Error: soft red
- Success: soft green

Avoid:
- aggressive colors
- high saturation UI

------------------------------------
UI STYLE

- rounded cards (small radius)
- soft shadows
- minimal borders
- clean spacing

------------------------------------
IMPORTANT RULE

UI must reduce cognitive load, not increase it.
