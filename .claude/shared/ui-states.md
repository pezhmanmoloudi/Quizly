
UI States System (Quizly)

------------------------------------
LOADING STATES

- skeleton loaders for decks/cards
- no spinners unless necessary

------------------------------------
EMPTY STATES

- always show guidance text
- include action button

------------------------------------
ERROR STATES

- user-friendly messages only
- never show raw errors
- always provide recovery action

------------------------------------
SUCCESS STATES

- minimal confirmation feedback
- no heavy animations

------------------------------------
IMPORTANT

States must guide the user, not distract them.
