
Study Flow UI (Quizly)

------------------------------------
CORE FLOW

1. Show flashcard front
2. User attempts recall (no hints)
3. User taps "Show Answer"
4. Reveal back content
5. User self-evaluates:
   - Again
   - Hard
   - Good
   - Easy
6. Update progress instantly
7. Load next card

------------------------------------
UI RULES

- no distractions during study
- full-screen focus mode
- single card visible at a time
- no navigation during session

------------------------------------
INTERACTION RULES

- tap to flip
- swipe optional (mobile)
- instant feedback

------------------------------------
IMPORTANT

Speed of interaction > visual effects
