
Dashboard UI (Quizly)

------------------------------------
LAYOUT STRUCTURE

1. Header
- minimal navigation
- user progress summary

2. Deck List
- each deck shows:
  - name
  - progress
  - due cards count

3. Quick Actions
- Start Study
- Create Deck

------------------------------------
RULES

- dashboard must be scannable in 3 seconds
- no clutter
- prioritize "Start Learning"

------------------------------------
EMPTY STATES

- no decks → show create deck CTA
- no cards → guide user to add flashcards

------------------------------------
IMPORTANT

Dashboard is not for exploration — it is for action.
