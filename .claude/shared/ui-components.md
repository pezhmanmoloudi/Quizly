
Quizly UI Components System

------------------------------------
CORE COMPONENTS

1. Button
- primary / secondary / danger
- always minimal design

2. Card
- used for decks, flashcards
- simple border or shadow

3. Flashcard Component
- front/back flip behavior
- instant interaction
- no animation delay

4. Progress Indicator
- shows learning progress
- minimal bar or dots

5. Input Fields
- clean, large touch targets
- mobile-friendly

------------------------------------
RULES

- components must be reusable
- avoid duplication
- no overly complex components
- keep logic out of UI components

------------------------------------
IMPORTANT

UI components must support learning speed, not visual complexity.
