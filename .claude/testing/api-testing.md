API Testing Rules (Quizly)

FOCUS:
- authentication
- authorization
- validation errors
- response structure consistency

RULES:
- test all status codes
- test invalid requests
- test unauthorized access
- test pagination
- ensure API contract stability (/api/v1)

EDGE CASES:
- large datasets (pagination stress)
- empty responses
- invalid input formats

IMPORTANT:
API reliability is critical for frontend stability.
